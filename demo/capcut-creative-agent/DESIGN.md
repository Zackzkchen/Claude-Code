# 全民创作 Agent · 剪映 PC 端「无限画布 + Agent 对话」MVP 交互设计

> 本文回答一个问题：**无限画布的 MVP 最小交互版本应该做到哪一步。**
> 结论先说：MVP 只需要 **5 组交互 + 1 套血缘规则 + 1 条 Agent↔画布双向通道**，其余画布能力（手动连线、编组、minimap、协作光标）都可以砍到下一版。
> 同目录的 `index.html` 是这套设计的可操作 Demo。

---

## 1. 产品定位与信息架构

桌面端「全民创作 Agent」不是一个对话框，而是 **一张会长出成品的创作图谱**。

```
┌──────────────────────────────── 剪映 PC 客户端 ────────────────────────────────┐
│  标题栏｜开始创作   全民创作 Agent   我的空间                    交互说明 一键演示 │
├──────────────────────────── 左：无限画布（主舞台）──────────┬─── 右：Agent 对话 ──┤
│  · 素材节点：文本 / 图片 / 视频                             │  · 消息流           │
│  · 产物节点：分镜、人物图、场景图、商品图、镜头、成片        │  · 任务卡（分步）    │
│  · 连线 = 生成血缘（谁由谁生成、用哪种能力生成）             │  · 产出节点回链      │
│  · 视图工具：缩放 / 适配 / 整理布局                         │  · 上下文胶囊        │
│  · 底部 Dock：新增文本 / 图片 / 视频                        │  · 输入框 + 快捷指令  │
└────────────────────────────────────────────────────────────┴────────────────────┘
```

三条设计原则：

1. **画布是唯一事实来源**：Agent 的产物必须落在画布上，而不是停留在对话气泡里。对话只负责"下指令 + 汇报 + 回链"。
2. **每个产物都要能溯源**：任何节点都能回答"我是谁生成的、用什么能力生成的"。这是画布相对于时间轴/列表的核心价值。
3. **一次只暴露必要的能力**：节点上的操作按父节点类型收敛（文本能生图/生视频，图片能生视频，视频能取封面），不做通用大菜单。

## 2. MVP 最小交互集（P0，必须做）

### 2.1 视口：4 个手势就够

| 交互 | 输入 | 说明 |
| --- | --- | --- |
| 平移 | 空白处拖拽 / 空格+拖拽 / 中键拖拽 / Alt+拖拽 | 面向大众用户，**空白左键拖拽默认是平移**（不是框选），学习成本最低；光标用 grab 明示 |
| 缩放 | 滚轮（以光标为锚点）、右下角 −/＋ | 缩放范围 20%~220%，超出无意义 |
| 适配画面 | 按钮 / `Shift+1` | 内容变多后的"回家"按钮，必做 |
| 恢复 100% | 按钮 / `Shift+0` | 与适配配合，避免用户迷路 |

> 不做：无限画布的**无限**只体现在坐标不设边界；不做世界地图 minimap、不做标尺、不做网格吸附。点阵背景随缩放变化，已经足够提供空间感。

### 2.2 界面密度：卡片默认只显示内容

第一版把标题、类型徽标、来源脚注、派生计数、⊕ 手柄全常驻在卡片上，结果**每张卡片都在喊**，十几个节点的画布就糊了。现在的规则是「如无必要勿增实体」：

```
默认（未 hover / 未选中）                hover 或选中
┌──────────────────┐                  [✦] [✎] [⧉] [↓] [✕]   ← 凸巴：只有图标，停上去才出文案
│                  │                  ┌──────────────────┐
│   只有内容本身    │        →         │   只有内容本身    │
│                  │                  └──────────────────┘
└──────────────────┘                  脚本 · 示例  ← 来自 xxx   ← 标题/来源，同样只在此时出现
```

- **常驻的只有内容**：文本就是文本，图片就是图片，视频是封面 + 一个很轻的时长角标（用来和图片区分）。生成中/失败这类状态本身就占据内容区，不再额外挂徽标。
- **图标 + tooltip**：凸巴上的功能全部只给图标，鼠标停 0.2s 才浮出文案。文本给「继续生成 / 编辑 / 复制 / 下载 / 删除」，图片给「继续生成 / 查看详情 / 下载 / 删除」，视频给「查看详情 / 下载 / 删除」。
- **右键是同一套能力的第二入口**：节点右键 = 该类型能做的事（菜单里文案是必要的，所以保留文字）；多选右键 = 「合成为一条成片」；空白右键 = 新建三类节点 + 整理布局 / 适配画面。
- **需要文案的地方不省**：菜单项、对话面板、详情栏、空状态一律保留文字——图标化只适用于「一眼能猜到」的高频小功能。

同一条原则也用在画布外围：右上角三个按钮（整理布局 / 适配画面 / 缩放）收成图标，底部 Dock 从「文本 + 两行说明」收成「图标 + 文本」，画布左上只留「8 节点 · 7 关系」。

### 2.3 素材节点：3 类 × 2 种来源

| 节点 | 新建方式 | 内容来源 |
| --- | --- | --- |
| 文本 | 双击画布空白处 / Dock「文本」 | 新建即进入编辑态，**光标就位，直接键盘输入**；之后双击卡片才重新进入编辑 |
| 图片 | Dock「图片」 | 卡内只有两个入口：`上传本地` / `AI 生成` |
| 视频 | Dock「视频」 | 同上 |

本地文件可以直接拖到画布空白处（自动判类型建节点），或拖到空节点上（直接填充）。

### 2.4 派生生成：两种节奏，取决于"提示词够不够"

手动菜单只留三类基础动作 —— 「人物图 / 场景图 / 商品图」这种语义化的三选一从画布菜单里撤掉了，交给右侧 Agent 用一句话表达，画布只留最少的按钮：

| 父节点 | 动作 | 节奏 | 连线标签 |
| --- | --- | --- | --- |
| 文本 | 文生图 | **立刻生成**（文本本身就是提示词） | `文生图` |
| 文本 | 文生视频 | **立刻生成** | `文生视频` |
| 文本 | 拆分镜（1 → 3 条文本） | **立刻生成** | `拆分镜` |
| 图片 | 图生视频 | **先落空节点**，等用户补一句 | `图生视频` |
| 图片 | 再生成一版 | 立刻生成 | `再生成` |
| 多选（≥2） | 合成为一条成片 | 立刻生成 | `合成`（多对一） |

**为什么图生视频要多一步？** 一张图不足以说清"镜头要怎么动"。所以点了图生视频之后：

```
[图片] ──图生视频（虚线）──▶ ┌─────────────────────┐
                            │ ▣ 参考图 · 商品主图  │  ← 选中的那张图被继承进来，看得见
                            │ ┌─────────────────┐ │
                            │ │补充运镜/动作…    │ │  ← 光标已经在这里
                            │ └─────────────────┘ │
                            │        [ 生成 ]      │
                            └─────────────────────┘
```

空节点 + 虚线连线在点击的瞬间就出现（血缘关系先立住），用户补完一句再生成；生成时提示词自动带上「参考『商品主图』，……」。而文生图不需要这一步，因为父节点的文本已经是提示词——**同一个"继续生成"，节奏由信息是否充足决定，而不是由 UI 统一规定。**

生成过程的三段式反馈缺一不可：

1. **占位节点立刻出现**在父节点右侧（不能等生成完才出现，否则用户不知道点没点上）；
2. 占位节点显示 **进度 + 提示词**，连线是 **浅灰虚线流动**（表示"在生成"）；
3. 完成后占位替换为成品，连线变实线并显示能力标签。

### 2.5 选择与编辑：够用就好

- 单击选中；`Shift` 点选多选；`Shift`+空白拖拽**框选**（框选是"多选合成"的必要前置，成本很低，建议进 MVP；但要把默认的空白拖拽让给平移）
- 拖拽移动（多选整组移动）
- `Delete` 删除（连带清理其连线）、`Ctrl/⌘+Z` 撤销 / `Shift+Z` 重做、`Ctrl/⌘+A` 全选、`Enter` 打开选中节点（文本→编辑，媒体→预览）
- 「整理布局」：按血缘层级重排（同一代同列，从左到右就是生成顺序）——**画布用户最怕乱，这个按钮比对齐吸附更值**

### 2.6 血缘表达：MVP 只做这 4 件事

1. **有向连线 + 能力标签**：连线中点的标签写清"用什么能力生成的"，这是逻辑关系可读的关键；
2. **血缘高亮**：选中节点时，其祖先 + 后代链路高亮，其余节点/连线淡出到 50% 左右，一眼看清"这个东西是怎么来的、又派生出了什么"；
3. **血缘小字**：hover / 选中时卡片下方那行「标题 ← 来自 X」（多父显示「← N 个素材」）；要看完整血缘路径就进详情预览页，不必常驻在卡片上；
4. **自动布局**：子节点默认排在父节点右侧一列、按批次垂直居中，重叠时自动向下避让。**MVP 不给用户"连线自由"，先把方向锁成从左到右。**

### 2.7 查看详情 = 局部放大预览（不是另一个页面）

每张卡片右上角有 <kbd>⤢</kbd>（选中后的悬浮条也有「查看详情」，双击卡片同效）。点开是一个"预览页"，但它的本质是**把这块画布放大**，而不是另一套详情界面：

| 设计要点 | 做法 | 为什么 |
| --- | --- | --- |
| 同一套视觉 | 复用画布的卡片组件、连线曲线、能力标签、缩放/平移手势 | 用户要一眼认出"我还在那张画布上，只是凑近了看" |
| 范围收敛 | 只渲染 **当前节点 + 直接上游 + 直接下游 + 同批产物**，其余不画 | 这就是"局部"的定义；也天然避免大图谱下的性能问题 |
| 默认放大 | 打开时缩放到当前节点占舞台一半以上（≈150%~250%），上下游故意露在画面边缘 | 边缘露出的卡片是"这里还连着东西"的线索，用户会自己往外拖 |
| 素材更清楚 | 占位素材按 2 倍分辨率重绘同一张图（种子不含尺寸，构图完全一致） | 放大预览必须真的看得更清，否则只是把模糊的图拉大 |
| 卡片放不下的信息进详情栏 | 来源、状态、提示词、素材尺寸/时长/字数、血缘路径、下游产物、操作 | 卡片要保持可扫读，细节留给详情栏 |
| 可以继续往下走 | 点上下游卡片就换成它当主角；<kbd>←</kbd> <kbd>→</kbd> 在同批产物间横向翻看；血缘路径 chip 可直接跳到任意祖先 | 预览页不是终点，是"沿着血缘游走"的另一种姿势 |
| 退出是连续的 | 打开时画布本体也同步凑近该节点，<kbd>Esc</kbd> 退出后视线落在同一个地方 | 避免"进去出来发现画布跑到别处了" |
| 右侧对话不被遮 | 预览层只盖住画布区，Agent 对话仍然可用 | 用户看着大图就能直接说"这张重新生成，光再软一点" |

预览页里**不做**的事（留到下一版）：局部重绘 / inpainting、多版本 A/B 对比、逐帧看视频、导出下载。MVP 只保证"看清 + 溯源 + 继续生成"。

### 2.8 单色视觉：不用色相怎么分层

Demo 采用黑白灰单色体系（画布是创作主体，素材本身才是画面里唯一该有颜色的东西，UI 不该跟素材抢注意力）。去掉色相后，信息要靠这四招编码：

| 要区分的东西 | 单色下的做法 |
| --- | --- |
| 节点类型 | 徽标用**三种填充方式**：文本 = 实心白底黑字、图片 = 中灰底、视频 = 透明描边（底部 Dock 与生成菜单沿用同一套） |
| 选中 / 未选中 | 选中给**纯白 1px 描边 + 外发光**，未选中是深灰描边 |
| 血缘链路 | 相关连线转**白**并加粗，无关节点降到 50% 左右不透明度（单色下不能压太狠，否则卡片上的字会糊掉） |
| 生成中 / 已完成 | 生成中是**浅灰流动虚线 + 骨架微光**，完成后是实线；状态一律配文字徽标（`生成中 42%`、`AI 生成`、`本地`） |
| 最终成品 | 成片卡片更大、亮色描边、徽标**反白**（黑字白底），是画面里最亮的一块 |

一条经验：单色方案里**任何状态都必须有文字兜底**，因为"红=失败、绿=完成"这条捷径没了。

## 3. 节点状态机

```
文本： 新建 ──▶ 编辑中 ⇄ 就绪            （Agent 写入时逐字打字机效果）

图片/视频：
  新建(empty) ──上传本地──▶ 就绪(ready, 来源=本地)
      │
      └──AI 生成──┐
                  ├─▶ 待输入(prompt) ──补一句──▶ 生成中(0~100%) ──▶ 就绪(ready, 来源=AI)
  图生视频派生 ────┘                                  └──▶ 失败(failed) ──重试──┘
  （待输入态会带着上游的参考图，连线此时已经是虚线，血缘先立住）

  文生图 / 文生视频派生 ──▶ 直接进入 生成中（父节点文本就是提示词，不必再问一遍）
```

非就绪状态必须在内容区里就能看见（骨架 + `生成中 42%` + 提示词、或失败 + 重试），否则批量生成时用户无法判断哪张好了。已就绪的节点则什么状态文字都不显示——干净是默认值。

## 4. Agent 与画布的双向通道

### 4.1 画布 → 对话（上下文）

- 选中节点后，输入框上方出现**上下文胶囊**：「已选中 *脚本 · 示例*，指令将基于它执行」，并可一键取消；
- 快捷指令随选中类型切换：选文本给「生成人物图 / 拆分镜 / 直接生成视频」，选图片给「把这张图变成视频 / 同系列图 / 看图写文案」；
- 这解决了对话式创作最大的歧义来源——**"这张图"到底指哪张**。

### 4.2 对话 → 画布（Agent 的原子能力）

Agent 不应该有"自由发挥"的画布权限，MVP 里它只能调用与手动交互**完全同构**的原子操作：

| 原子操作 | 对应手动交互 |
| --- | --- |
| `createNode(type, content)` | Dock 新建节点 |
| `generate(parentIds, action)` | 生成菜单里的某一项 |
| `link(from, to, label)` | 派生时自动连线 |
| `select(ids)` / `focus(id)` | 点选 / 双击定位 |
| `tidyLayout()` | 「整理布局」按钮 |

好处：Agent 做的每一步用户都能手动复现、手动修正，也能一键撤销。

### 4.3 执行时的可见性

- 画布顶部出现「Agent 正在操作画布…」状态条；Agent 新建的节点带一次白色呼吸高亮；
- 对话里给 **任务卡**：分步状态（等待 / 执行中 / 完成），完成的步骤补上结果摘要（如"已生成 3 张图：人物 / 场景 / 商品"）；
- 任务卡底部列出**产出节点 chips（带缩略图）**，点击飞行定位到画布对应节点——这是对话与画布之间最重要的一条回链；
- 视野跟随：生成时自动把"父节点 + 新产物"框进视野，成片后整体 fit，避免用户在大画布里丢失焦点。

### 4.4 一句话到成片的完整链路（Demo 主线）

```
用户：帮我做一条国风护手霜的短视频
Agent：① 规划链路 → ② 写脚本（文本节点，打字机）
      → ③ 派生 人物图 / 场景图 / 商品图（一对多血缘）
      → ④ 场景图、商品图各自图生视频（图 → 视频）
      → ⑤ 两个镜头合成成片（多对一血缘）+ 整理布局
画布：脚本 ─▶ 3 张图 ─▶ 2 个镜头 ─▶ 成片，每条连线都带能力标签
```

## 5. 明确不进 MVP（P1 / P2）

| 能力 | 判断 |
| --- | --- |
| 手动从手柄拉线连接任意两节点 | **已砍**。⊕ 手柄与凸巴的「继续生成」重复，而且手动连线会引入语义歧义（连了线代表要重新生成吗？） |
| 卡片上常驻标题栏 / 类型徽标 / 来源脚注 / 派生计数 | **已砍**。都挪进 hover 的凸巴与小字行，或者进详情预览页 |
| 画布菜单里的「人物图 / 场景图 / 商品图」三选一 | **已砍**，收敛成「文生图」。这类语义化意图更适合对 Agent 说，而不是给所有人多两个按钮 |
| 视频的「提取封面 / 延长镜头」、图片的「同系列图 / 看图写文案」、节点「复制」 | **已砍**。低频，且都不承担"表达血缘"这个核心叙事 |
| 编组 / 画框 / 便签 / 批注 | P1。多人评审场景才需要 |
| minimap 缩略导航、书签视图 | P1。节点数 < 30 时「适配画面 + 整理布局」已足够 |
| 节点内局部重绘、垫图权重、参数面板 | P1。MVP 只给"提示词 + 重新生成" |
| 时间轴级剪辑（进剪映主编辑器） | P1，但要预留出口：成片节点 → 「导入时间轴继续剪」 |
| 视野锁定（Agent 生成时不自动移动视野，只在边缘提示新产物） | P1。MVP 默认视野跟随更利于理解；用户开始精修单个节点后才需要锁定 |
| 任务卡步骤折叠 / 完整执行日志 | P1。步骤 ≤ 5 条时平铺更易读 |
| 多人协作光标 / 版本对比 / 分支 | P2 |
| 画布内直接播放带音频的成片、逐帧预览 | P2，MVP 用封面 + 时长 + 模拟进度即可表达 |

## 6. 关键交互细节（容易踩的坑）

1. **手势冲突**：文本节点内是真实输入框，所以画布快捷键（`Delete`、`Ctrl+Z`）在输入态必须让位；节点内的滚动与画布缩放要分层拦截。
2. **点了没反应的感觉**：生成必须先建占位节点，再跑进度；否则 2~4 秒的等待会让用户重复点击。
3. **画布会乱**：自动落点要做重叠避让（本 Demo 用"向下顺延"策略），并提供一键「整理布局」兜底。
4. **批量生成的可控性**：同一批产物错峰启动（本 Demo 每个间隔 260ms），避免进度条同时跳动造成"假死"观感。
5. **多父节点的血缘展示**：成片这类多对一节点，脚注不要只显示第一个父节点，要显示「来自 N 个素材」并支持一次性框选。
6. **富文本流式输出**：Agent 气泡里带标签的富文本一次性渲染，避免逐字输出时把 `<b>` 切断。
7. **视觉层级**：成片节点（链路终点）需要与中间素材有明确区分（本 Demo 给了更大的卡片 + 亮色描边 + 反白的「成片」徽标）。
8. **空白拖拽给谁**：专业画布（Figma/Miro 的选择工具）把空白左键拖拽给了框选，但"全民创作"的用户第一反应是**拖动画布**。本 Demo 实测后把默认让给平移、框选退到 `Shift`+拖拽，并用 grab 光标做暗示——这类默认值分歧一定要在 MVP 里定死，否则文档和实现会各说一套。
9. **图标化的边界**：只有"一眼能猜到"的高频小功能适合退化成图标（编辑、复制、下载、删除、放大）。菜单项、详情栏、对话面板这些需要读的地方硬塞图标只会让人猜谜。
10. **hover 才出现的东西要给足触达面积**：凸巴浮在卡片正上方 8px，鼠标从卡片移到凸巴的路径上不能有断层，否则一移就消失。
11. **前台/后台节流**：生成进度用时间戳计算，并在 `visibilitychange` 回前台时立刻补一次 tick；否则窗口被遮挡时浏览器把定时器节流到秒级/分钟级，用户回来会看到"卡在生成中"。

## 7. 验收清单（可以照着点一遍）

- [ ] 空白拖拽能平移，滚轮能以光标为锚缩放，`Shift+1` 能适配画面
- [ ] 静止时每张卡片上**只有内容**：没有标题栏、没有徽标、没有常驻按钮
- [ ] 鼠标移到卡片上，上方浮出图标凸巴、下方浮出「标题 ← 来源」；鼠标停在图标上 0.2s 出现文案
- [ ] 双击空白处新建文本并光标就位；双击文本卡片重新进入编辑；双击图片/视频打开局部放大预览
- [ ] 右键文本 / 图片 / 视频 / 多选 / 空白，五种菜单内容都和对象匹配
- [ ] 文本 →「文生图」：**立刻**出现占位卡 + 流动虚线 + 进度，完成后连线变实线且标签是「文生图」
- [ ] 图片 →「图生视频」：**立刻**出现空视频节点，里面能看到刚选的那张图作为参考图，光标已在提示词框里；补一句再点生成才开始跑
- [ ] 生成完成后连线由虚线变实线，节点提示词里带着「参考『xxx』」
- [ ] `Shift` 多选两个以上素材 → 右键「合成为一条成片」，成片节点连着每个素材
- [ ] 选中任一节点，其血缘链高亮、其余淡出；凸巴里的 ⤢ 能打开局部放大预览
- [ ] 凸巴上的「下载」能真的把文本存成 .txt、把图片存成 .jpg
- [ ] 对话里说「帮我做一条国风护手霜的短视频」，画布上自动长出 脚本 → 图 → 镜头 → 成片，任务卡可点击定位
- [ ] `Delete` 删除节点连带删连线，`Ctrl/⌘+Z` 能撤销
